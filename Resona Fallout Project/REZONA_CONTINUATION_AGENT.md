# REZONA CONTINUATION AGENT

## Mission
Continue the Fallout 1 + Fallout 2 reconstruction from the supplied Rezona source snapshot.

## Operating mode
1. Read `PROJECT_STATE.md` before changing anything.
2. Read `SOURCE_EXTRACT.md` for the authoritative Rezona instruction set.
3. Preserve working systems.
4. Implement one coherent subsystem at a time.
5. Record every meaningful change in `CHANGELOG.md`.
6. Update `PROJECT_STATE.md` after each task.
7. Never mark a feature VERIFIED without an explicit test/acceptance result.
8. Never fabricate files, assets, source material, or test results.
9. Keep game data separate from engine/system code wherever practical.
10. Keep the project compatible with the full target scope instead of creating disposable prototypes.

## Output required after each task
- Task
- Files changed
- Systems affected
- Implementation status
- Verification performed
- Known issues
- Next task
