# Campaign Data Boundary

The reusable engine and data-driven content framework is implemented up to the campaign-content boundary.

## Intentionally stopped here

No Fallout 1 or Fallout 2 campaign dataset is being generated in this pass.

No bulk campaign-specific maps, NPC rosters, creatures, item catalogs, dialogue trees, quest scripts, faction definitions, encounter tables, merchant inventories, endings, or original campaign assets are included here.

The engine provides the schemas and runtime primitives needed to import authorized campaign data without hard-coding campaign content into the engine.

Import the authorized Fallout 1 campaign dataset into the content model, validate references, then repeat for Fallout 2.
